# 联网研究

当用户需要实时或外部信息时，执行：搜索 → 筛选可信来源 → 抓取正文 → 总结。

- 只引用结果中带出处的信息；无法验证的说法明确标注"未能核实"。
- 优先使用 `search` 获取链接列表（单次调用最快）；需要正文时只对少数关键
  URL 使用 `fetch` / `fetch_batch`，避免无差别抓取大量页面。
- 仅在明确需要"搜索 + 阅读"合并完成时才用 `research`，并把 `depth` 控制在
  2 以内，不要多次重复执行同一研究。
- 单次搜索失败或返回空结果时，不要反复重试；基于已获得的信息回答，并说明
  当前信息来源受限。
- 总结时区分"来自搜索结果的事实"与"你的推断"。

## B 站视频补充

当问题属于教程、学习、操作演示或讲解类，且视频形式能更直观地解答时，
额外调用 `search(query, engines=["bilibili"])` 查一次 B 站视频。
- 只有视频标题与问题重合度高、确实能解答问题时才附链接：在回答末尾附
  1~2 个视频链接，用视频标题作链接文字；不要批量罗列或为凑数硬附。
- 普通新闻、事实核查等不需要视频的问题，不要额外搜索 B 站。
