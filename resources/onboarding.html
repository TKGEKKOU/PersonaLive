首次启动需要准备 Docker（MySQL/Milvus），点击后自动拉起并进入主界面。

启动后怎么做（简版手册）
  1. 设置页：配置 LLM API Key（必填）、Embedding、联网搜索、本地语音 ASR/TTS（可选）。
  2. 资料页：创建角色，上传资料并生成入库，之后角色就有专属知识。
  3. 对话页：选择角色开始聊天，可发语音消息。
  4. 接入页：可选配置 QQ（OneBot 11 / NapCat）。
  5. 结束项目：侧边栏左下角按钮，可只停服务或同时暂停 Docker 容器。

退出 PersonaLive？

确认后将依次：

  • 停止 FastAPI 服务
  • 停止 ASR / Embedding 后台进程
  • 关闭窗口并退出程序

Docker 容器按【退出时】策略处理：保持运行

容器继续运行，下次启动最快。
