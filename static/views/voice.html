  3. 音频/分离上传音频并提取人声
  5. 片段试听并勾选干净片段
  7. 训练训练专属音色

01 视频

上传视频，自动提取音轨。支持 mp4 / mkv / webm / mov / m4a / avi，最大 400 MB。

拖入视频，或点击选择 上传后自动完成：提取音轨 → 分离人声 → 截取干净片段

02 音频/分离

可一次上传多个音频（支持 mp3 / wav / m4a / flac 等）；先自动检测格式并转为 WAV，确认后再手动开始人声分离。

上传音频（可多选） 多个音频会按顺序拼接后统一分离；wav / mp3 / m4a / flac / ogg 等常见格式

    03 片段

    自动截取的干净语音片段可试听、下载；也可以自行上传多段干净音频作为候选。勾选片段后进入训练（GPT-SoVITS，建议尽量多选、合计 1~10 分钟）。

      投放已处理的干净片段（可多选） 跳过前面的视频/音频步骤，直接从此处开始；wav / mp3 / m4a / flac 等，单段建议 3~15 秒

      04 训练

      用已勾选的干净片段训练 GPT-SoVITS 专属模型（后台进行，可先离开页面）。训练完成后，音色会出现在下方「训练音色」列表中，可在角色编辑页绑定。

      训练音色（GPT-SoVITS）

      已训练完成的音色会出现在角色编辑页的「声音」选择中。
