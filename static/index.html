参数说明与兼容要求

应用内置：默认从国内 ModelScope 下载 Qwen/Qwen3-Embedding-0.6B 到项目 models 目录，自动优先使用 GPU，不可用时回退 CPU。

自定义模型 ID 必须兼容标准 Transformers 或 Sentence Transformers；应用不会执行模型仓库中的远程代码。下载失败时可手动切换 Hugging Face，不会静默改用外网源。

通义千问：从阿里云百炼获取 Key，推荐模型 text-embedding-v4、维度 512。

自定义接口：必须提供 OpenAI 兼容的 /embeddings 接口。更换模型或维度后需要重建 Milvus Collection 并重新入库。

切分建议：普通资料使用 1000 / 150；短问答可使用 600 / 100。重叠不能超过切分长度的 25%，修改后只影响新入库资料。
