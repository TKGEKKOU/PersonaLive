启动与停止

手动启动 / 停止

启动：先 docker compose up -d 准备 Milvus（应用数据存本地 SQLite），再运行 .\.venv\Scripts\python.exe -B main.py；页面地址 http://127.0.0.1:17000/static/index.html。

停止：桌面版关闭窗口时按【退出时】策略处理 Docker；浏览器版请手动停止 Python 进程，需要保留容器用 docker compose stop。

使用流程

五个模块怎么用

设置：配置 LLM API Key（必填），可选用 Embedding、联网搜索与本地语音 ASR / TTS；【退出时】板块管理 Docker 容器策略。

资料：创建角色、上传资料并生成入库，角色即可获得专属知识。

对话：选择角色开始聊天，支持语音消息与自动播放。

接入：可选配置 QQ（OneBot 11 / NapCat）等平台接入。

插件：加载本地插件扩展能力。
