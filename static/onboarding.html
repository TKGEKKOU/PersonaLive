PersonaLive 使用指南

这个页面是只读指南；一键启动请使用桌面版，或按下方命令手动启动。

启动与停止展开

启动：docker compose up -d 后运行 .\venv\Scripts\python.exe -B main.py；页面地址 http://127.0.0.1:17000/static/index.html。

停止：侧边栏左下角“结束项目”按钮（可勾选同时暂停 Docker 容器）。

使用流程展开

1. 设置页：配置 LLM API Key（必填）；可选配置 Embedding、联网搜索、本地语音 ASR/TTS。

2. 资料页：创建角色，上传资料并生成入库，角色获得专属知识。

3. 对话页：选择角色开始聊天，支持语音消息。

4. 接入页：可选配置 QQ（OneBot 11 / NapCat）。
